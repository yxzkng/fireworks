# 여의도 불꽃 지도

2026 서울세계불꽃축제(9/5 토, 20:00~21:10) 장소별 실시간 혼잡도 + 현장 사진 제보.

**사이트**: https://claude.ai/code/artifact/2bf93fbc-4f20-4e3d-a6b3-ab33f2956aee

## 두 가지 버전이 있습니다

| | 이 폴더 (아티팩트) | [`web/`](web/) (Vercel) |
|---|---|---|
| 지도 | 직접 그린 한강·여의도 윤곽 | **카카오맵** |
| 저장소 | `claude.use('db')` | **Supabase** |
| 사진 | 256KB 제한 | **제한 없음** |
| 상태 | **지금 바로 동작** | 배포 설정 필요 |

카카오맵은 도메인 등록이 필수인데 아티팩트는 주소가 매번 바뀌는 UUID라 등록할 수 없습니다.
그래서 고정 도메인이 생기는 Vercel 버전을 따로 뒀습니다. 배포 절차는 [`web/README.md`](web/README.md) 참고.

아티팩트 버전은 그대로 유지되니, Vercel 배포가 늦어져도 축제 당일 쓸 것은 확보돼 있습니다.

제보 기능은 지금 바로 동작합니다. 아래는 공공데이터(혼잡도·예측)를 켜는 절차입니다.

## 구성

```
[Cloudflare Cron] ──5분마다──> [서울시 API] ──> [KV 저장소]
                                                    │
[접속자] ──HTTPS──> [Worker] ──읽기만──────────────┘
    │
    └── claude.use('db') ──> 제보·사진 (실시간 공유)
```

**핵심**: 접속자는 KV에 저장된 값만 읽습니다. 몇 명이 접속하든 **서울시 API 호출 수는 변하지 않습니다.**

## API 호출 예산 — 하루 988 / 1,000회

서울시 인증키는 **하루 1,000회** 제한입니다. 이 한도 안에서 중요한 곳을 자주 갱신하도록
거리별로 주기를 나눴습니다.

| 등급 | 장소 | 축제 시간대(12~24시) | 그 외 |
|---|---|---|---|
| HOT | 여의도, 여의도한강공원, 여의서로, 노들섬 | **5분** | 60분 / 심야 4시간 |
| WARM | 이촌·반포·양화·망원한강공원, 노량진, 용산역, 영등포, 합정역 | 20분 | 2시간 |
| COLD | 서울역, 홍대, 신촌·이대역, 고속터미널, 잠실·뚝섬한강공원, 강남역 | 60분 | — |

주기를 바꾼 뒤에는 **반드시 예산을 다시 확인**하세요:

```bash
cd proxy && node check-budget.mjs
```

한도를 넘으면 실패(exit 1)합니다.

> **한도 늘리기**: 열린데이터광장 **활용사례(갤러리)**에 인증키와 함께 사이트를 등록하면
> 제한 없이 쓸 수 있습니다. 등록 후에는 `worker.js`의 `tiersToFetch()`에서
> 심야 조건을 없애고 WARM/COLD 주기를 당기면 됩니다.

## 배포

### 1. 인증키 발급 (2분)

1. https://data.seoul.go.kr 회원가입
2. 상단 **Open API** → **인증키 신청** (즉시 발급)

> ⚠️ **인증키는 공유하지 마세요.** 채팅·커밋에 넣지 말고, 노출됐다면 폐기 후 재발급하세요.

### 2. KV 저장소 만들기

```bash
cd proxy
npx wrangler login
npx wrangler kv namespace create CITY
```

출력된 `id`를 `wrangler.toml`의 `id = "여기에_KV_ID를_넣으세요"` 자리에 붙여넣습니다.

### 3. 배포

```bash
npx wrangler secret put SEOUL_API_KEY   # 발급받은 키
npx wrangler secret put ADMIN_KEY       # 아무 문자열 (수동 수집용)
npx wrangler deploy
```

### 4. 첫 데이터 채우기

Cron은 5분 뒤부터 도니, 처음 한 번은 수동으로 채웁니다.

```bash
curl "https://<주소>.workers.dev/collect?key=<ADMIN_KEY>"
curl "https://<주소>.workers.dev/meta"     # 수집 상태·오늘 호출 수 확인
```

### 5. 사이트에 연결

`template.html`에서 주소를 넣고 다시 빌드합니다.

```js
const WORKER_URL = 'https://<주소>.workers.dev';
```

```bash
python3 build.py    # index.html 재생성
```

Claude Code에 "재배포해줘"라고 하면 같은 링크에 반영됩니다.

### ERROR-500은 서버 장애가 아닙니다

서울시는 **등록되지 않은 장소명**에도 `ERROR-500 "서버 오류입니다"`를 반환합니다.
`여의나루역`, `여의도역`, `63빌딩`, `마포대교`가 여기 해당합니다(목록에 없음).

장소를 추가하려면 전체 121곳 목록에서 고르고 검증하세요:

```bash
curl -s -H "Referer: https://data.seoul.go.kr/SeoulRtd/" \
  "https://data.seoul.go.kr/SeoulRtd/api/hotspot-category?page=1&category=전체보기&count=300" \
  | python3 -m json.tool | grep area_nm

cd proxy && ./verify-areas.sh <인증키>
```

추가 시 `worker.js`의 `HOT`/`WARM`/`COLD`, `area-coords.json`(좌표), `template.html`의 `NOTES`를 함께 수정하고 `check-budget.mjs`로 예산을 확인하세요.

## 설계 메모

**지도** — 아티팩트 CSP가 외부 이미지를 막아 타일 지도를 쓸 수 없습니다. 그래서 한강·여의도·
노들섬 윤곽과 다리를 Canvas로 직접 그립니다. 불꽃축제엔 오히려 이쪽이 읽기 쉽습니다 —
강과 섬, 사람이 어디 몰렸는지만 보이면 되니까요.

- **원 크기 = 인원** (제곱근이라 면적이 인원에 비례)
- **원 색 = 혼잡도** (액센트 금색과 분리한 의미색)
- **클러스터링**: 화면상 46px 안에 든 장소를 묶고, 확대하면 자연히 풀립니다. 덩어리를 누르면 그쪽으로 확대합니다.

**정렬** — '붐비는 순'은 **관람 가능한 곳을 먼저** 놓습니다. 그러지 않으면 늘 붐비는
강남역이 1위가 되어 자리 찾는 사람에게 쓸모없는 순서가 됩니다.

**데이터 출처 분리** — 공공데이터와 제보를 평균내지 않습니다. 기지국 추정은 광역 흐름에,
현장 제보는 "돗자리 깔 자리 있나" 같은 미시 정보에 강해서 섞으면 둘 다 흐려집니다.

**유입/유출** — 지하철 30분내 승하차를 비교해 "몰려드는 중 / 빠져나가는 중"을 표시합니다.
혼잡도 숫자에는 안 나타나고, 종료 후 귀가 러시 판단에 쓰입니다.

**사진** — 1024px·q0.7 자동 압축 (저장소 문서 한도 256KiB, base64는 +33%).
테스트에서 1.4MB → 138KB. GPS는 수집하지 않고, 고른 장소만 저장합니다.
신고 3건이면 자동으로 가려집니다.

**장애 대응** — Worker가 죽어도 지도·카드·제보는 그대로 동작합니다(테스트로 확인).
